## About

Learn-sphere is a front-end web project containing pages for home, courses, course detail, and about us sections. It demonstrates basic website navigation, layout, and content presentation using standard web technologies (HTML, CSS, JavaScript).

---

## Features

- Static pages including:  
  • Home (`index.html`)  
  • Course list (`course.html`)  
  • Course details (`course-details.html`)  
  • About us (`about-us.html`)  
- Simple navigation between pages  
- Use of assets (images, styles, logo)  
- Minimal JavaScript/interactive behavior
